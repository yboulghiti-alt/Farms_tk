# 🎮 GPU Benchmark & Comparison Tool

A web-based tool designed to compare the performance of various Graphics Cards (GPUs) across a curated selection of popular video games. This project helps gamers and PC builders make informed decisions based on real-world FPS data.

## 🔗 Live Demo
Check out the live site here: [View Project](https://yboulghiti-alt.github.io/Farms_tk/)

---

## 🚀 Key Features
* **Side-by-Side Comparison:** Easily compare FPS and performance metrics between different GPUs.
* **Game-Specific Data:** Benchmarks for demanding titles (e.g., Cyberpunk 2077, RDR2, Warzone).
* **Responsive Design:** Optimized for viewing on both desktop and mobile devices.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure for the comparison tables and content.
* **CSS3:** Custom styling for a modern, "gaming-inspired" dark UI.
* **GitHub Pages:** Fast and reliable hosting.
